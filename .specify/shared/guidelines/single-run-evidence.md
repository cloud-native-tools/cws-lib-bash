# 单次执行证据纪律(Single-Run Evidence Discipline)

> **Single Source of Truth**: 本文档是框架「单次执行证据」纪律的唯一定义处。任何命令、技能、代理或共享工作流引用本纪律时 MUST 以路径引用本文件,MUST NOT 复制规则文本。原则层声明见宪法原则 XV(`.specify/templates/constitution-template.md`);本文档由指令文件的 `## Single-Run Evidence Discipline` 章节以指针引用,该章节只承载摘要,细则归此处。

Agent 的工作充满昂贵执行——长时测试套件、构建、批量查询、远端调用。每一次这样的执行都是一次性的证据采集机会:**执行本身才是成本,完整输出近乎免费可留**。同一份证据 MUST NOT 被支付两次。

典型反模式:为回答"为什么慢/失败在哪"而把昂贵命令重跑一遍,只因第一次执行时把输出在管道里过滤掉了、或没开启耗时诊断——重跑意味着全额执行成本再付一次,还叠加两次运行间的不可复现风险(flaky 结果、状态漂移)。

---

## 昂贵执行的判定

本纪律按**执行成本**分级适用:

- **昂贵执行**(约束对象):长时测试套件、构建、批量查询、远端/网络调用——重跑成本显著高于留痕成本的执行。
- **廉价且无副作用的命令**(豁免):列目录、读文件等——重跑比纪律本身更便宜,不在范围内。
- 存疑时按昂贵处理(疑则从严)。

## 执行时全量捕获(Capture-in-Full)

昂贵执行 MUST 在**执行时刻**把四要素完整落盘为工件(日志文件):

1. **命令行原文**(含全部参数与开关);
2. **退出码**;
3. **完整 stdout/stderr**;
4. **墙钟耗时**。

落盘文件同时是外部记忆:证据不占对话上下文,又对后续每次查询可用(与 Token 效率纪律「摘要优先」协同——程序读原文、模型读节选)。

过滤视图(匹配行、计数、摘要)MUST 从该工件派生,MUST NOT 在流内管道中直接销毁原始输出:

- 反例(证据蒸发):`cmd 2>&1 | grep "FAILED" > failures.txt` —— 非匹配行在管道中丢弃,原始输出从未落盘。
- 正例(证据保全):`cmd 2>&1 | tee run.log | grep "FAILED" > failures.txt` —— 全量先落 `run.log`,过滤视图从工件派生。

信息压缩类默认开关(quiet/summary-only 模式)对昂贵执行 SHOULD 重新评估:它们在源头削减证据,与流内过滤同属「安静的销毁」。

## 诊断开关前置(Diagnostics-Before-the-Run)

工具提供的**无副作用 opt-in 诊断**(逐项耗时、verbose 日志、统计输出)SHOULD 在昂贵执行**开启在前**,而非等提问后补开:

- 执行一旦结束,未开启的诊断信息**永久不可补齐**——逐项耗时分布、verbose 明细都不在事后可恢复之列;
- 此时唯一补救路径是全额重跑,正是本纪律要消灭的反模式;
- 有副作用的诊断开关(拖慢执行、改变行为)不在此列,按其代价单独权衡。

## 消费留痕而非重跑(Consume-the-Record)

关于**已完成的执行**的任何后续问题——为什么慢、哪些失败、警告了什么、与基线相比如何——MUST 从留痕工件回答。

重跑的合法性判据只有一条:**获取新证据**——验证修复、行使已变更的状态。为找回第一次执行**已经产生过**的信息而重跑是经典反模式:全额成本付第二次,再叠加不可复现噪声(第二次的失败集与第一次未必可比)。

基线对比同样建立在留痕之上:失败清单排序落盘后,后续 diff 即可回答"新增了什么失败",无需再跑。

## 性能归因须实测(Measured-Durations-Only)

关于"为什么慢"的结论 MUST 基于留痕中**实际存在**的耗时数据(逐项耗时、时间戳),MUST NOT 基于:

- 记忆或直觉(执行细节不可靠);
- 专为回答该问题而发起的重跑(先有提问、后有数据,顺序已经颠倒——且重跑本身就违反上一节)。

---

## 判定边界

- 本纪律约束**证据的保全与消费方式**,不约束命令本身的选择与正确性(后者归各流程自身的验证纪律)。
- 留痕工件的位置与命名由执行它的流程决定;本纪律只要求"落盘且可再寻址"。
- 与 Token 效率纪律(`.specify/shared/guidelines/token-efficiency.md`)的边界:那侧管注入上下文的内容量(程序读原文、模型读摘要),本侧管昂贵执行的输出是否完整保全、后续是否重跑——两侧同向:文件是廉价外部记忆。
