# run-skills — 运行未注册技能的统一入口

## Goal

给定一个技能标识(名称或规范路径),定位其 `SKILL.md` 并**遵照该文件正文执行**这个技能,把技能自身的产出转述给调用方。run-skills 是「internal 技能不被 agent 发现」规则(`.specify/skills.md`)的**具名例外**——入口自身必须可被 agent 直呼,才能运行其他不可直呼的技能;例外条款与多宿主降级路径见该指南。概念语义真源:词汇表条目「技能分类标注 (Skill Classification)」与 goal `.specify/goal/command-logic-as-classified-skills/goal.md`。

## Input Contract

- **输入**:技能标识——名称(如 `my-draft`)或规范路径(如 `.specify/skills/internal/my-draft/SKILL.md`),来自调用方参数或会话上下文;名称可省略扩展名。
- **消歧**:输入若命中 `/speckit.*` 命令名(命令面,非技能),报告该名字属命令面并指向对应 `/speckit.*` 入口,不强行执行。
- **递归**:目标是 run-skills 自身时照常执行并披露这一点;无特殊分支。

## Workflow

### 1. 解析(确定性,位置搜索顺序内联于此)

按以下顺序取**首个命中**;命中即在输出中披露所选路径:

1. `skills/internal/<name>/SKILL.md`(dev 规范层 internal)
2. `skills/external/<name>/SKILL.md`(dev 规范层 external)
3. `.specify/skills/internal/<name>/SKILL.md`(installed internal 镜像)
4. `.specify/skills/<name>/SKILL.md`(installed external 镜像)

- **已裁定(2026-10-14)**:同名多命中时 dev 规范层(canonical)优先于 installed 镜像——canonical 是真源(镜像模型:`.specify/skills.md` § Mirrors),跑真源还能让镜像漂移显形。
- **信任边界(已裁定)**:显式路径输入 MUST 落于上述位置集内;越界路径停在此处,输出可行动错误(路径 + 已知位置集),不猜测、不降级(快速失败纪律,真源 `.specify/shared/guidelines/fast-fail.md`)。
- **零命中**:停在异常点,逐项列出上述 4 个已搜索位置,提示 create-skills 创建或核对名称。
- **无效制品**:`SKILL.md` 存在但 frontmatter 缺 `name`/`description` 或正文为空——停在异常点,指出路径与缺陷。

### 2. 注册状态提示(尽力检测,非阻断)

按工作区内宿主扫描目录近似判断目标是否已被 agent 发现(`.claude/skills`、`.qoder/skills`、`.github/skills` 等符号链接是否可达该技能)。判不准也照常执行;已注册目标在输出附「该技能可能可直接斜杠调用」的非阻断提示。注册是宿主相关观测、非框架事实——本提示不构成判定承诺。

### 3. 执行(加载并遵照,不内联)

- 读取命中路径的 `SKILL.md` 正文,**将其作为本次运行的最高执行指引**,输入按调用方接线;技能自带 `${SKILL_HOME}`(技能自有资源)/`${SKILL_WORKDIR}`(运行时产物)路径约定按其正文与 `.specify/skills/create-skills/SKILL.md` 的路径约定解释。
- 把目标技能的产出/报告**转述**给调用方;MUST NOT 将目标技能的逻辑复制进本技能。
- 运行中发现的异常按目标技能自身的治理处理;run-skills 自身对「无法解析/无效制品/越界路径」三类异常停在本层并上送可行动错误。

### 4. Runtime-mode 门控

真源 `.specify/shared/workflow/runtime-mode.md`。`${SKILL_WORKDIR}/.specify/` 不存在(非 Spec-Kit 部署)时:external 目标技能照常运行,spec-kit 耦合步骤(如引擎调用、Feedback 步)按其正文中的门控降级;**internal 目标技能拒绝执行**并输出可行动错误(internal 技能按 goal T-002 配合 `.specify/` 目录结构,离开该结构无运行意义)。

## Boundaries

- 只做「解析 → 执行 → 转述」;不承载任何具体技能的业务逻辑,不替代斜杠命令入口(已注册技能优先直呼)。
- 不修改目标技能文件;目标技能自身的 improve/create 语义归 `/speckit.skills` 路由族(improve-skills / merge-skills / think-skills / create-skills)。
- 多宿主降级:发现面无法注册 internal 技能的宿主,经 `/speckit.skills` 的 run 意图路由以显式路径加载同一技能,功能等价(指南 § Where skills live)。
